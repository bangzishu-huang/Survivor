# Survivor
A top down shooter game, where you have to try to survive as long as possible while creatures are trying to continuously attack you.

Essentially this is just a very simple rpg shooter game where you, as the player, are suppose to eliminate all these monsters that are trying to attack you. There are a bunch of different monsters that can always appear out of no where, so the element of surprise will keep the player continuously engaged. The real skill of this particular game is that you need to leave a specific amount of space between you and the monster in order for the bullets to engage.

I realized that I've never really made any games or projects that utilized the traditional gaming "WASD", so this was the project to do that. Alongside, having some fun developing the attack system for both the actual player and also the enemies, I learned a crazy ton from just doing normal debugging. The process of trying to debug some code gave me a chance to dig in deep to a specific section of my code and actually take time to understand what was going on inside. While, yes the final product was very tempting, I feel like the progress I made throughout creating this game gave me a solid foundation of python itself.

Controls: WASD in order to move around and use your mouse to shoot

AI Used: None

# Tech Slack

- Hosting: GitHub Pages

# Features
- A 3 life system is incorporated for the player regardless of difficulty
- A variety of different difficulties available to the player for many variety of gaming types
- Walking animations present on both the player and the monsters
- Monster randomly spawn in and attempt to run towards you
- A gun that is essentially floating around the player's radius that is their main source of weapon to protect
